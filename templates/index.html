Run a BPE experiment

Pick an input, tell the analyser what kind of text it is, and choose how many merges to learn.

You choose the category — it's not detected automatically. It decides which cleaning rules are applied before the run (indentation is preserved for code, collapsed for English prose).

With a step, the analyser runs k = 0, step, 2·step, … up to k, so the results page can show utility, vocabulary and distinct tokens across the whole sweep. Repeated (input, k, category) combinations reuse the stored row — no duplicates.

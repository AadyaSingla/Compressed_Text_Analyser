You choose the category — it's not detected automatically. It decides which cleaning rules the Clean button applies (indentation is preserved for code, collapsed for English prose).

With a step, the analyser runs k = 0, step, 2·step, … up to k, so the results page can show compression utility and vocabulary size across the whole sweep. Repeated (input, k, category) combinations reuse the stored row — no duplicates.

Clean applies the category's cleaning rules and puts the result back in the text box for you to check — it doesn't run BPE. Run analysis runs BPE on whatever's in the box, cleaned or not.
